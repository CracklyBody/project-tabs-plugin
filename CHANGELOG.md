# Project Tabs Changelog

## Unreleased

## 1.0.0 - 2026-10-29

### Added

- Open projects shown as tabs in the center of the main toolbar, in every project window
- Click a tab to switch; the window you switch to takes the current window's size and position
- Close a project from its tab: × button, middle-click or context menu (Close, Close Others, Close Tabs to the Right)
- Next/Previous Project Tab on the Next/Previous Project Window shortcuts, following the tab order
- Go to Project Tab 1–8 and Last (⌃⌥1…9 on macOS)
- Drag tabs to reorder; the order is kept across IDE restarts
- ＋ button: open a recent project or any folder as a new tab
- Reopen Closed Project Tab, Copy Project Path, Reveal Project Folder
- Overflow popup with speed search when tabs do not fit
- Settings under Tools | Project Tabs
- One-time suggestion to open projects in a new window, so each one becomes a tab
